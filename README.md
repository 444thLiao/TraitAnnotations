# TraitAnnotations
Scripts for annotating Ruegeria genomes



## Scripts


- `AnnoMultipleTraits_Others.py`: Annotation code for 

    * islandviewer
    * macsyfinder (CasFinder, CONJScan, TFFscan, TXSScan)
    * What_the_Phage
- `AnnoMultipleTraits.py` and `AnnoMultipleTraits_Summary.py`
    * antiSMASH
    * resfinder
    * RGI and CARD databases
    * BacARscan
    * KEGG
    * IS (insertion sequences) : ISESCAN and digIS
    * abricate
    * CRISPRCasFinder
    * VF (virulence factor)
    * alien_hunter
    * COG databse (though diamond)
    * interproscan
    * Plascad
    * pseudofinder


# Tips

The script provided here do not account for each software installtion. Just a wrapper for running each software. Please prepare installed software and adjust the setting inside the script.
